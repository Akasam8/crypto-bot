Set up the Run now button (once per device)

The button needs a GitHub key that is allowed to start the bot. It's saved only in this browser on this device, never on the website or in the repo.
  1. Open GitHub's new token page, name it "crypto-bot run button", pick a long expiry.
  2. Repository access: Only select repositories, choose crypto-bot.
  3. Permissions: add Actions and set it to Read and write. Nothing else.
  4. Click Generate token, copy it, paste it below.
